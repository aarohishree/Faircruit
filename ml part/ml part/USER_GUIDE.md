## What is This System?

The Faircruit ML Assessment System is an automated tool that evaluates job candidates by:
- Analyzing their CV/Resume
- Conducting competency-based assessments
- Generating professional reports and certificates

Think of it as an AI hiring assistant that helps you make better, faster, and more objective hiring decisions.

## Understanding the Assessment

### What Gets Evaluated?

#### 1. CV Analysis (15 points)
The AI examines the candidate's CV for:
- Relevant experience
- Required skills
- Educational background
- Overall fit for the role

#### 2. Competency Assessment (85 points)
The candidate answers questions testing:
- Multiple competencies (e.g., Problem Solving, Communication)
- Different skill levels (Awareness, Application, Mastery, Influence)
- Real-world scenarios

**Total Score**: 100 points

### How Scoring Works

#### Competency Levels

**Awareness (0-25%)**
- Basic understanding
- Can explain concepts
- Entry-level knowledge

**Application (26-50%)**
- Can use skills practically
- Solves standard problems
- Intermediate level

**Mastery (51-75%)**
- Expert-level skills
- Handles complex scenarios
- Advanced proficiency

**Influence (76-100%)**
- Leadership level
- Teaches and mentors others
- Creates new methods

#### Hiring Recommendations

| Score Range | Recommendation |
|-------------|----------------|
| 85-100 | +++  STRONGLY RECOMMENDED |
| 70-84  | ++   RECOMMENDED |
| 55-69  | +    CONSIDER WITH CAUTION |
| 0-54   | -    NOT RECOMMENDED |

## Using the Reports

### Certificate (PDF)

**Purpose**: Give to successful candidates

**Contains**:
- Candidate name and job role
- Assessment date
- Overall score (out of 100)
- Competency levels achieved
- Key strengths
- Unique certificate ID

**What to do with it**:
- Send to qualified candidates
- Add to candidate's file
- Use in job offer packages

### Admin Report (PDF)

**Purpose**: Detailed evaluation for hiring managers

**Page 1 - Summary**:
- Candidate information
- Overall scores
- Competency-by-competency breakdown
- Quick reference table

**Page 2 - Details**:
- In-depth analysis per competency
- Rubric-based reasoning
- Specific strengths identified
- Areas for improvement
- CV evaluation details
- Overall recommendation

**What to do with it**:
- Review before interviews
- Share with hiring team
- Keep in candidate records
- Use for comparison

### Admin Report (TXT)

**Purpose**: Quick reference, easy searching

**Advantages**:
- Open in any text editor
- Use Ctrl+F to search
- Copy relevant sections
- Email-friendly format

**Same content as PDF** but in plain text format.

## Customizing for Your Organization

### Adding Job Roles

1. **Open** `competency sheet.xlsx`
2. **Create New Sheet**: Name it after the job role
3. **Add Competencies**: Follow this format:

| Competency Name | Awareness (0-25%) | Application (26-50%) | Mastery (51-75%) | Influence (76-100%) |
|----------------|-------------------|---------------------|------------------|-------------------|
| Problem Solving | Understands basic concepts | Can solve standard problems | Designs complex solutions | Creates innovative frameworks |
| Communication | Knows importance | Communicates effectively | Leads presentations | Influences organizational communication |

4. **Save** the file
5. **Run** assessment - new role will appear automatically

### Modifying Existing Roles

1. **Open** `competency sheet.xlsx`
2. **Find** the job role sheet
3. **Edit** competency descriptions
4. **Save** and close
5. Changes take effect immediately


## Best Practices

### For Accurate Assessments

1. **Use Complete CVs**:
   - Include all relevant experience
   - List specific skills
   - Mention certifications

2. **Ask Candidates to Answer Thoughtfully**:
   - Take time to think
   - Provide specific examples
   - Be honest about experience

3. **Review Results Carefully**:
   - Don't rely solely on scores
   - Read detailed feedback
   - Consider context
   - Use as one input in hiring decision

### For Fair Evaluations

1. **Consistent Rubrics**:
   - Use same competency definitions for same role
   - Update rubrics periodically
   - Keep levels clearly defined

2. **Objective Criteria**:
   - Let AI handle initial screening
   - Review reports without bias
   - Focus on competency evidence

3. **Candidate Experience**:
   - Explain the assessment process
   - Provide clear instructions
   - Allow reasonable time for answers
